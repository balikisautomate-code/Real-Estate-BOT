This folder contains the foundational specifications and design documents for the **PrimeHomes Realty — Real Estate Lead Bot**.

## How to use these documents

1. Start with the **PRD** to understand *what* we are building and *why*.
2. Use the **Architecture** and **Database** specs for the overall system design.
3. Follow **API**, **AI**, **n8n**, and **UI/UX** specs when implementing each layer.
4. Keep **IMPLEMENTATION.md** and **TASK.md** updated as work progresses.

> **Rule for AI coding agents:** Always read the relevant specification before making changes. Do not invent architecture that contradicts these documents.
